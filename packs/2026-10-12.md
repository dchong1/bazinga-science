### Q1. [CORE · mc · +2 pt] `ft-c06`

A student says: 'I changed the drop height AND the marble mass to get clearer results.' What should you say?

- **A.** Good idea — more changes = clearer science
- **B.** Problem — two IVs at once; you can't tell which caused the effect
- **C.** Fine if you measure twice
- **D.** Only wrong if the crater gets deeper

_Answer key (facilitator only):_ **B** — One IV per test. Want both? Run two separate fair tests.
_Science idea:_ Confounding variables muddy the causal story.

### Q2. [WARM · mc · +1 pt] `ft-w03`

Testing if a heavier marble makes a deeper crater in sand. What is the independent variable (the one you change on purpose)?

- **A.** Depth of the crater
- **B.** Mass of the marble
- **C.** Type of sand
- **D.** How you measure

_Answer key (facilitator only):_ **B** — Independent = what you change. Dependent = crater depth (what you measure).
_Science idea:_ IV = change; DV = measure; controls = keep the same.

### Q3. [CORE · spot_unfair · +2 pt] `ft-c07`

Hypothesis: 'If plants are happier, then they grow taller because happiness helps.' What's weak here?

- **A.** 'Happier' isn't measurable; IV needs a clear, measurable change
- **B.** Plants don't grow
- **C.** Height isn't a dependent variable
- **D.** Nothing — happiness is scientific

_Answer key (facilitator only):_ **A** — Replace 'happier' with something measurable (hours of light, ml of water, etc.).
_Science idea:_ Operational definitions make variables testable.

### Q4. [STRETCH · mc · +3 pt] `en-s02`

Same mass, different drop heights. Higher drop → deeper crater. What changed, and why deeper?

- **A.** Height → more speed → more kinetic energy
- **B.** Height → more mass
- **C.** Height → less gravity
- **D.** Nothing about energy; sand just got softer

_Answer key (facilitator only):_ **A** — Higher drop → more gravitational potential energy → converts to more speed/KE.
_Science idea:_ GPE → KE as the object falls.

### Q5. [CORE · mc · +2 pt] `ft-c08`

Why do scientists often repeat a measurement several times?

- **A.** To spot odd results and see if the pattern is reliable
- **B.** Because one trial is illegal
- **C.** To change more variables each time
- **D.** Repeats replace the need for control variables

_Answer key (facilitator only):_ **A** — Repeats improve reliability; they don't replace keeping controls constant.
_Science idea:_ Reliability ≠ fair test — you need both.
